## 1. Summary

- Briefly describe what the validation checks.
    
- Keep the explanation high-level and concise.
    

## 2. Decision Flow

- Include a Mermaid flowchart showing the validation decision flow.
    
- Show the start, validation decision, and possible outcomes.
    
- Keep the diagram simple.
    

## 3. Validation Rules

- List the conditions the data must satisfy.
    
- State what happens when validation passes or fails.
    
- Do not include implementation details.
    

## 4. References

- Use a bulleted list of relevant documentation links.
    
- Format each reference as `- [Title](link)`.
    
- Include only relevant references, such as related data models or validation rules.
    
- Do not repeat the full contents of referenced documents.
